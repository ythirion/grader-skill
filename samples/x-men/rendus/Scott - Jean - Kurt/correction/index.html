00 Synthèse 15/20

32 commits réguliers (2 à 8 minutes), des préfixes red / green / refactor tenus, sept passes de refactoring et l'ajout de Pitest : la pratique est exemplaire. Le cœur métier ne l'est pas. Le seul EID valide testé, 12345673, a une clé fausse (la bonne est 25), et le code implémente reste % 97 + 1 au lieu de 97 - reste % 97 : un EID valide comme 19800767 est refusé. C'est le cas d'école du manque de triangulation. La correction porte sur le code commité (HEAD) : la copie de travail supprime ce code et ajoute trois implémentations individuelles non commitées, dont deux déclarées générées par IA. Correction par lecture du code, sans exécution des tests.
