04 Constats communs

  • acquis
    Commits fréquents et préfixés dans les trois rendus : l'historique git permet de suivre le cycle TDD.
  • acquis
    Tests paramétrés utilisés partout pour multiplier les cas à moindre coût.
  • critique
    La triangulation reste le point faible : un rendu valide une clé de contrôle fausse avec un seul exemple.
  • à améliorer
    Les entrées malformées (null, longueur, caractère en tête) ne sont pas toujours traitées avant le découpage.
  • à améliorer
    Hygiène du dépôt : target/ ou .idea/ versionnés et travail final non commité dans les trois rendus.
  • à améliorer
    Le format de préfixe imposé (red: / green: / refactor:) n'est suivi à la lettre que par un groupe.
